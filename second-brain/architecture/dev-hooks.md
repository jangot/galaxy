# Dev-хуки для тестирования (`window.__galaxy`)

Инструмент для браузерного QA-агента `tester` (`/qa`) и для ручной отладки. Работает
**только в dev-сборке** (`npm run dev`, `import.meta.env.DEV`): в прод-бандле нет ни
разбора параметров, ни `window.__galaxy`, ни кода снимка (модуль `game/dev-hooks`
подключается динамическим `import()` внутри DEV-ветки и вырезается Vite).

Код: `src/game/dev-params.ts` (параметры URL), `src/game/dev-snapshot.ts` (снимок),
`src/game/dev-hooks.ts` (объект хуков), подключение — `src/main.ts`; пауза цикла —
`GameLoop.pause()/resume()` в `src/engine/loop.ts`.

## Параметры URL

Комбинируются: `http://localhost:5173/?seed=1&paused=1&level=3&shield=0`.

| Параметр   | Формат                                  | Некорректное значение            |
| ---------- | --------------------------------------- | -------------------------------- |
| `seed=N`   | десятичное целое `0 … 4294967295`       | игнор → seed `Date.now()`        |
| `paused=1` | только ровно `1`                        | (`0`, `true`, пусто) → без паузы |
| `level=N`  | десятичное целое `>= 1`                 | уровень 1                        |
| `shield=N` | десятичное целое `0 … 5` (`MAX_SHIELD`) | игнор → `START_SHIELD` (2)       |

- `paused=1` — цикл стартует в паузе: кадры рисуются, тиков нет, игра двигается только
  через `__galaxy.step()`.
- `level` и `shield` сохраняются при возврате на титул после game over (новая игра
  начнётся с тем же уровнем и щитом).

## API `window.__galaxy`

Хуки появляются **асинхронно** после загрузки страницы — сначала дождаться
`window.__galaxy` (цикл уже стоит в паузе при `paused=1`, тиков до этого нет).

- `step(n = 1)` — синхронно прогнать `n` тиков симуляции (60 тиков = 1 с), затем один раз
  нарисовать кадр; возвращает снимок (то же, что `state()`). `n` — целое `>= 1`, иначе
  `RangeError`.
- `press(action)` / `release(action)` — зажать / отпустить действие. Имена — только
  `left`, `right`, `up`, `down`, `fire`, `start` (список — `__galaxy.actions`); неизвестное
  имя → `TypeError`. Коды клавиш (`Space`, `Enter`) не принимаются.
  - «Нажатие» (`pressed`: выстрел, Enter) срабатывает только в тик нажатия. Удержание
    `fire` не стреляет повторно — для нового выстрела `release('fire')` + `press('fire')`.
  - `press` уже зажатого действия нового нажатия не даёт.
  - Без `doubleShot` в полёте не больше одного выстрела: новый `press('fire')` выстрелит,
    только когда прежний выстрел исчез.
- `pause()` / `resume()` — пауза цикла rAF. После `resume()` время паузы отбрасывается —
  рывка нет.
- `state()` — JSON-снимок (ниже).
- `actions` — допустимые имена действий.

Типичная последовательность «начать игру»:
`press('start'); step(1); release('start')`.

## Снимок `state()`

Только примитивы, массивы и объекты (`JSON.stringify` без потерь), копия — со
следующими тиками не меняется.

- `tick` — число тиков симуляции с загрузки страницы (и от rAF, и от `step`).
- `paused` — стоит ли цикл в паузе.
- `scene` — `'title'` | `'play'` | `'over'` | `'unknown'`. `'over'` — это та же сцена боя с
  `battle.phase === 'over'` (Game Over — не отдельная сцена).
- `battle` — `null` на титуле, иначе:
  - `level`, `phase` (`playing` | `cleared` | `over`), `phaseTicks`, `score`, `shield` (уровень щита `0 … 5`);
  - `player`: `x`, `y`, `state` (`active` | `down` | `invulnerable`), `stateTicks`,
    `canBeHit`, `isLost`, `maxShots` (1 или 2), `powerUps { fastShot, doubleShot }`,
    `shots [{ x, y, speed }]`;
  - `enemies`: `alive` — число живых (строй + пике + возврат; взрывающиеся не живые),
    `list [{ kind, row, col, state, stateTicks, x, y }]` — все, кроме `dead`
    (`exploding` в списке), `shots [{ x, y }]` — вражеские выстрелы;
  - `bonuses`: `asteroid { x, y, dir, bonus, state, stateTicks } | null`,
    `capsule { kind, x, y } | null`, `spawnTick` (тик уровня следующего вылета — нового
    астероида или повтора; `null`, когда ничего не ждёт), `retryBonus` (бонус ожидающего
    повтора несбитого астероида; `null` — повтор не ждёт), `levelTicks` (тики `playing` в
    текущем уровне).

Координаты — сырые (левый верхний угол, логические px 256×240), **бывают дробные**:
покачивание строя, дрейф астероида, пике по 1/2 px. На экране рисуется `Math.floor`.

## Детерминизм

Воспроизводимо только вместе: **тот же `seed` + `paused=1` + та же последовательность
`step` / `press` / `release`**. Звёзды титула тратят общий `rng`, а seed боя берётся из
него в момент Enter, поэтому число тиков до Enter влияет на весь бой. Без паузы rAF
добавляет тики между командами — результат не воспроизводится.

`step` без паузы разрешён: тики `step` идут синхронно между кадрами и смешиваются с тиками
rAF (`tick` в снимке считает оба). Для воспроизводимых кейсов — только с паузой.

## Потеря фокуса (`blur`)

При потере фокуса окна ввод отпускает все клавиши. В `step` действия, зажатые через
`press`, восстанавливаются перед каждым тиком (без нового «нажатия», лишнего выстрела не
будет). В режиме `resume()` (тики от rAF) восстановления нет — после переключения вкладки
повторить `press`.

## Полезные константы

| Константа               | Значение  | Что                                          |
| ----------------------- | --------- | -------------------------------------------- |
| `INVULNERABLE_TICKS`    | 120       | неуязвимость после удара по щиту             |
| `GAME_OVER_DELAY_TICKS` | 60        | от гибели (удар без щита) до `over`          |
| `LEVEL_PAUSE_TICKS`     | 90        | пауза между уровнями (`cleared`)             |
| `START_SHIELD`          | 2         | щит на старте                                |
| `MAX_SHIELD`            | 5         | максимум щита                                |
| `BONUS_FALLBACK_POINTS` | 500       | очки за бесполезный бонус                    |
| окно астероида          | 300 … 900 | тиков уровня (`levelTicks`) до появления     |
| задержка повтора        | 300 … 900 | тиков `playing` от ухода несбитого астероида |
| `EXTRA_SHIELD_FIRST`    | 5000      | первый порог очков за уровень щита           |

## Рецепты

- **Щит на пределе:** `?seed=…&paused=1&shield=5` → начать игру, `step` до появления
  астероида (`bonuses.spawnTick` / `bonuses.asteroid`), сбить его; если в капсуле `shield`
  — поймать: `shield` остаётся 5, `score` +500.
- **Повтор астероида:** `?seed=…&paused=1&shield=5` → начать игру, `step` до
  `bonuses.spawnTick`, не стрелять, `step(252)` → `retryBonus` не `null`, `step` до нового
  `spawnTick` → астероид с тем же `bonus`.
- **Быстрый game over:** `?paused=1&shield=0` → начать игру, дождаться попадания (или
  подставиться под врага), через 60 тиков после гибели `scene === 'over'`; Enter
  (`press('start'); step(1); release('start')`) → титул, новая игра — снова без щита.
- **Поздний уровень:** `?paused=1&level=3`.

## Не входит (кандидаты на отдельную задачу)

- готовые сценарии (`?scenario=…`) и сеттеры состояния (`setShield`, «поставить
  астероид», `setScore`);
- восстановление зажатых `press`-клавиш после `blur` в режиме `resume()`.
