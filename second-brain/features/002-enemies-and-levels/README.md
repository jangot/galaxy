# Фича 002: Враги и уровни

**Статус:** готова

## Суть

Враги и прогрессия сложности. Наверху — строй разных врагов, покачивающийся
влево-вправо; враги вылетают из строя и атакуют игрока. Игрок их сбивает; строй
уничтожен — следующий уровень, сложнее предыдущего.

## Требования

Из обсуждения с владельцем (2026-11-11):

- **Строй:** враги двигаются строем вправо-влево.
- **Типы врагов:** враги разные (разные виды/поведение), не один тип.
- **Атаки:** в какой-то момент враги из задних рядов начинают вылетать из строя и
  атаковать игрока (пикирование / таран).
- **Уровни** — рост сложности:
  - скорость врагов растёт с уровнем;
  - на более высоких уровнях вылетевшие враги ещё и стреляют по игроку;
  - ещё выше — появляются специальные враги, которые вылетают несколькими группами
    и потом стреляют.
- **Переход уровня:** строй уничтожен целиком → следующий уровень.
- **Попадания в обе стороны:** выстрел игрока уничтожает врага; выстрел врага или
  столкновение с врагом поражает игрока.

## Вне рамок

- Жизни, Game Over, счёт, рекорд, HUD — отдельная фича. Что происходит при поражении
  игрока в рамках этой фичи (перезапуск уровня, временная неуязвимость и т. п.) —
  решает дизайн, минимально.
- Звук.
