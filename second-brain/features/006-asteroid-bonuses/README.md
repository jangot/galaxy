# Фича 006: Астероиды с бонусами

**Статус:** готова

## Суть

В игре появляются бонусы (улучшения). Их источник — астероиды: иногда на поле
вылетает астероид, по нему надо попасть, и из него получается бонус. Это даёт игроку
цель помимо строя и способ усилить корабль.

## Требования

Проговорено владельцем (2026-11-12):

- Иногда вылетают **астероиды**; по астероиду надо попасть, чтобы получить из него
  какой-то бонус.
- Виды бонусов:
  - **дополнительная жизнь**;
  - **увеличение скорости пули**;
  - **возможность выпустить две пули** (сейчас на экране не больше одного своего
    выстрела — `game-design.md`).

Не проговорено — решит дизайн / владелец: как часто и откуда вылетают астероиды и как
летят; с одного ли попадания разбиваются; бонус берётся сразу при попадании или
выпадает и его надо поймать кораблём; какой бонус выпадает (случайно, по очереди,
по виду астероида); сколько действуют улучшения пули (до гибели, до конца уровня,
навсегда), складываются ли; опасен ли астероид для корабля; очки за астероид;
отображение улучшений в HUD (фича 004 оставила место под `powerUps`); как доп. жизнь
сочетается с пределом 5 жизней (фича 005).
