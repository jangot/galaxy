# Реестр фич

Запись фичи — файл `{NNN}-{name}.md` или папка `{NNN}-{name}/` с `README.md`
(+ `status.md` — «начинать сессию отсюда», при необходимости `questions.md`,
`plan.md`, `review.md`). Заводить запись сразу, когда фича начинает обсуждаться,
а не по завершении.

В записи: суть, статус, точки входа в коде, связанные задачи, ссылки.

Фичи, прошедшие `/design-feature`, — всегда папка: `README.md` (суть, требования,
задачи), `design.md` (архитектура от агента architect), `dev-review*.md` (отзывы
агента developer), `discussion.md` (ответы архитектора по пунктам).

Статусы: идея → проектирование → спроектирована → в работе → готова.
