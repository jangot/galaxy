# Фича 008: Щит корабля вместо запаса жизней

**Статус:** готова

## Суть

Меняем концепцию жизней (фича 005, бонус `L` из фичи 006): у игрока **одна жизнь**, но перед
кораблём — **щит** с несколькими уровнями прочности. Попадание по кораблю со щитом не
убивает его, а ослабляет щит; щит меняет цвет от зелёного к красному и затем исчезает.
Попадание по кораблю без щита — конец игры. Бонусы «подзеленяют» щит. Идея владельца: это
заодно снимает проблему запаса нескольких кораблей (иконки, возрождения, предел 5).

## Требования

(со слов владельца)

- Жизнь одна. Перед кораблём рисуется щит («экран»).
- Когда враги в нас врезаются (попадание), щит меняет цвет: зелёный → жёлтый → красный →
  щит исчезает. Только когда щита нет, попадание по нам заканчивает игру.
- Градаций от зелёного к красному можно сделать больше; запас — «на 6 жизней».
- Игра начинается не с полного щита, а с середины («с жёлтого»), так что по факту на старте
  примерно как 3 жизни.
- Бонусы делают щит зеленее (повышают уровень).

Решения владельца (design.md, В1–В9):

- шкала щита 0…5, старт 2 (жёлтый): гибель на 3-м ударе; максимум 5 (зелёный) — гибель на 6-м;
- вражеский выстрел и таран — по −1; протаранивший враг гибнет, очки как за сбитого в полёте;
- после удара по щиту — 2 с неуязвимости с миганием, корабль остаётся на месте (передышка
  короче прежних 3 с — оценить на приёмке); возрождения нет, удар без щита — game over;
- щит повышает только капсула `L` (+1, внешне без изменений); на максимуме и повторные
  `S`/`D` — 500 очков; пороги 5000/15000/… — +1 к щиту, сверх максимума пропадает;
  порог, пройденный после гибели, игру не спасает;
- в панели вместо иконок жизней — шкала из 5 сегментов без подписи.
