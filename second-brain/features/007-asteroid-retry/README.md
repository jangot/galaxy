# Фича 007: Повторный пролёт несбитого астероида

**Статус:** спроектирована

## Суть

Сейчас (фича 006) астероид с бонусом появляется раз за уровень; если игрок его не сбил и
астероид улетел за экран — бонус потерян до следующего уровня. Нужно, чтобы несбитый
астероид через какое-то время снова пролетал, давая игроку ещё шанс получить бонус.

## Требования

- Астероид улетел за экран несбитым → через некоторое время прилетает снова.
- Остальная механика фичи 006 не меняется (скорости, размер, безопасность астероида,
  капсула, «на поле не больше одного бонусного предмета»).
- Решения владельца (design.md, В1–В4): задержка повтора — случайно 5–15 с фазы
  `playing` (как первое появление); повторов без ограничения в пределах уровня, пока не
  сбит; бонус тот же; при смене уровня ожидающий повтор отменяется.

## Вне рамок

- Повтор не пойманной капсулы — не просили (капсула, которую не поймали, по-прежнему
  пропадает), если владелец не решит иначе.
