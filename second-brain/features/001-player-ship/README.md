# Фича 001: Корабль игрока — движение и выстрел

**Статус:** готова — все задачи выполнены (код не закоммичен)

## Суть

Первый играбельный элемент: корабль игрока внизу экрана, которым можно управлять и
стрелять. Фундамент для следующих фич (враги, коллизии, жизни, HUD).

## Требования

Из `game-design.md` и обсуждения:

- Корабль внизу экрана, движется **только влево-вправо**, не выходит за края.
- Управление: влево/вправо — стрелки или A/D, выстрел — Space или Z (уже есть в
  `src/engine/input.ts`).
- Выстрел летит вверх; на экране одновременно **не больше одного** своего выстрела.
- Выстрел, ушедший за верх экрана, исчезает — можно стрелять снова.
- Фон — существующий звёздный фон (`src/game/starfield.ts`).
- Спрайт корабля — свой, оригинальный, в 8-битном стиле.

## Вне рамок

Враги, попадания, смерть, жизни, счёт и HUD, звук — отдельные фичи.
