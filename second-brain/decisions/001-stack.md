# ADR 001: Стек

**Дата:** 2026-11-10 · **Статус:** принято

## Решение

TypeScript + Vite + Canvas 2D без игрового фреймворка; Vitest, ESLint, Prettier; npm.

## Почему

- Игре такого масштаба фреймворк (Phaser и т.п.) не нужен — свой маленький движок
  проще контролировать и тестировать.
- Canvas 2D с логическим разрешением 256×240 и целочисленным масштабом даёт честный
  пиксель-арт.
- Vite — быстрый dev-сервер и сборка, Vitest использует тот же конфиг.
