# Задача: Верхняя панель (HUD)

## Суть задачи

Вывести вверху экрана информационную панель: счёт, номер уровня и жизни. Реально
меняется пока только уровень; счёт и жизни — заглушки до фич очков и жизней. Панель
устроена так, чтобы позже добавить секцию улучшений (новое поле, своя зона, своя функция
отрисовки).

## Детали и требования

Решения владельца (2026-11-11, фича 004, В1–В7):

- Показываем только **уровень, счёт, жизни** (рекорд и флажки уровней — позже).
- **Две строки:** подписи сверху красным (`HUD_LABEL_COLOR = '#ff5a3c'`), значения под
  ними белым (`HUD_VALUE_COLOR = '#ffffff'`). Слева `SCORE` / `000000` (6 цифр с ведущими
  нулями), по центру `LEVEL` / номер, справа иконки жизней в строке значений.
- **Жизни** — иконки, уменьшенный силуэт корабля (`LIFE_ICON_SPRITE` в `art.ts`, не больше
  8×8); показывается **общее число жизней, включая текущий корабль** — заглушка 3.
- Панель рисуется **последней, поверх игры, без фона**; поле не сдвигается.

Архитектура (`design.md`):

- `src/game/hud.ts` — без canvas: `HudView { level, score, lives }`, `hudView(battle)`,
  `formatScore`, `formatLevel`, заглушки `PLACEHOLDER_SCORE` / `PLACEHOLDER_LIVES`,
  `HUD_HEIGHT = 24`, `interface HudZone { x, y, width, height }`, зоны `SCORE_ZONE`,
  `LEVEL_ZONE`, `LIVES_ZONE`, список `HUD_ZONES`, `LIFE_ICON_STEP`, `LIVES_ICON_SLOTS`
  (числа — в `design.md`).
- Номер уровня и счёт выровнены по левому краю подписи (переход 9 → 10 не сдвигает
  первую цифру). Уровень меняется в тик появления новой волны (панель читает
  `battle.level`, своего состояния нет).
- Иконки жизней — от правого края зоны влево.
- `src/game/hud-render.ts` — `drawHud(ctx, view)` по зонам, через шрифт из задачи 018.
- `PlayScene.render` — после `drawBattle` вызвать `drawHud(ctx, hudView(this.battle))`.
- Комментарий у `SHIP_Y` в `ship.ts` (жизни не внизу); `overview.md` (HUD; строка про
  нижние 16 px); `game-design.md` «Экран» (счёт, уровень, жизни — общее число, включая
  текущий корабль; рекорд и флажки — позже).

## Критерии готовности

- `hud.test.ts`: форматирование, заглушки, `startLevel` 1 и 3; зоны попарно не
  пересекаются и лежат в `0…SCREEN_WIDTH × 0…HUD_HEIGHT`; `HUD_HEIGHT ≤ 28`; размер
  `LIFE_ICON_SPRITE` ≤ 8×8. Тайминг смены уровня не дублировать (есть в `battle.test.ts`).
- `hud-render.test.ts`: при смене значения меняются только вызовы в зоне этой секции.
- Проходят `format:check`, `lint`, `typecheck`, `test`, `build`.
- Приёмка глазами (`acceptance.md`): `npm run dev` — панель читается, цвета и раскладка
  как утверждено, рисунок иконки жизни и вид шрифта утверждает владелец; номер уровня
  меняется при переходе (`?level=9` → 10); возвращающийся в строй враг и выстрел
  проходят под текстом.
