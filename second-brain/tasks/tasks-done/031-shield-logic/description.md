# Задача: Щит вместо запаса жизней — логика

## Суть задачи

Заменить запас жизней (фича 005) щитом корабля: жизнь одна, у `Player` — уровень щита
0…5. Удар по кораблю со щитом снимает уровень и даёт 2 с неуязвимости на месте; удар без
щита — гибель и game over, возрождения нет. Источники щита — капсула `L` и пороги счёта.
Отрисовка в этой задаче временная: иконки кораблей в панели показывают уровень щита
(дуга — 032, шкала — 033). Игра целиком работает и проверяема.

## Детали и требования

- `Player`: `shield`, `START_SHIELD = 2`, `MAX_SHIELD = 5`, `addShield(): boolean`
  (false на максимуме); новый автомат без возрождения; `DOWN_TICKS` удалён.
- Вражеский выстрел и таран — по −1; правило «не больше одного попадания за тик»
  сохраняется. Протаранивший враг гибнет, очки как за сбитого в полёте.
- После удара по щиту (в т.ч. 1 → 0) — `invulnerable` 2 с (`INVULNERABLE_TICKS`),
  мигание, корабль остаётся на месте и управляется.
- Удар при `shield = 0` → `down` (конечное), через `GAME_OVER_DELAY_TICKS = 60`
  (литерал в `battle.ts`) — `over`.
- Капсула `L` (вид `'life'` → `'shield'`, порядок `BONUS_KINDS` тот же, внешне без
  изменений) — +1; на максимуме — 500 очков (`applyBonus` через возвращаемое значение
  `addShield()`). Повторные `S`/`D` — 500 очков, как раньше.
- Пороги 5000/15000/… — +1 к щиту, сверх максимума пропадает; в `down` щит не растёт:
  порог, пройденный после гибели, игру не спасает (В7).
- `BattleOptions.shield`, `?shield=0…5` в dev-params, `shield` на верхнем уровне
  dev-снимка (вместо `lives`), `title-scene`/`main.ts`, переименования в `score.ts`,
  `bonus.ts`, `bonus-art.ts`, комментарии `collisions.ts`/`ship.ts`.
- HUD: `HudView.shield`; `drawLives` временно рисует `shield` иконок кораблей.
- rng щит не трогает; детерминизм сохраняется.
- Тесты — по таблице «031», правилу перевода `lives: k` → `shield: k − 1` и правилу
  разбиения кейсов из design.md (включая переворот `battle.test.ts:512–535` по В7, кейсы
  взрыва `battle-render.test.ts:262–306` с `shield: 0`).
