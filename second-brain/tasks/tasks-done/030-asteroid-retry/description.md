# Задача: Повторный пролёт несбитого астероида

## Суть задачи

Сейчас астероид с бонусом появляется раз за уровень, и если игрок его не сбил, бонус
потерян до следующего уровня. Нужно, чтобы астероид, ушедший за нижний край несбитым,
через случайные 5–15 с фазы `playing` прилетал снова с тем же бонусом. Изменение
сосредоточено в `BonusField`; плюс поле в dev-снимке, тесты и документы.

## Детали и требования

- Уход несбитым: до `update` астероид был `flying`, после — `gone` (сбитый проходит через
  `exploding`). `asteroid.ts` не меняется.
- Задержка повтора — случайная из того же `spawnWindow` (300…900 тиков), отсчёт только в
  `playing`; общий со `startLevel` метод `drawWindowTicks()`.
- Повторов без ограничения в пределах уровня, пока не сбит. Бонус тот же (rng на бонус не
  тянется), сторона и смещение — новые случайные (`dir, offset`).
- Ожидание — одна запись `pending: { tick, bonus } | null`; повтор назначается, только если
  ничего не ждёт вылета. `startLevel` отменяет ожидающий повтор. Астероид прошлого
  уровня, улетевший несбитым уже на новом уровне, не возвращается.
- Правило «на поле не больше одного бонусного предмета» сохраняется (повтор ждёт пустого
  поля).
- Порядок `update` — по «Потоку тика» design.md: запомнить `escaped` (бонус ушедшего) →
  `if (spawning) ticks++` → назначить повтор (1 вызов rng) → `if (!spawning) return` →
  проверка вылета. Порядок «назначение до вылета» несущий — причину записать в
  doc-комментарий `update`.
- Сценарии без ухода несбитым дают ту же последовательность rng, что в фиче 006.
- Новое: геттер `retryBonus`, поле `bonuses.retryBonus` в dev-snapshot; смысл `spawnTick`
  расширяется — тик следующего вылета (нового астероида или повтора).

## Критерии готовности

- Unit-тесты `bonus-field.test.ts` по разделу «Тестирование» design.md: повтор, тот же
  бонус, число вызовов rng через `queued(...)`, уход при `spawning = false`, отмена в
  `startLevel`; переписан тест `:101` («once per level»); `:126`, `:204`, `:250` без
  изменений.
- Интеграционный тест в `battle.test.ts`: время вылета повтора и отмена при смене уровня
