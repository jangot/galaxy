## Кейсы

### 1. Несбитый астероид прилетает снова — PASS

Источник: acceptance.md, кейс 1 (шаги 1–5); description.md — суть задачи.
Шаги (после загрузки, без стрельбы и движения):

```js
const g = window.__galaxy;
g.press('start');
g.step(1);
g.release('start'); // spawnTick 654, levelTicks 0, retryBonus null
g.step(653); // asteroid null, levelTicks 653
g.step(1); // asteroid {x:34, y:-12, dir:1, bonus:'fastShot', state:'flying'}, spawnTick null
g.step(251); // asteroid ещё flying, y 239
g.step(1); // asteroid null, retryBonus 'fastShot', spawnTick 1248, levelTicks 906
g.step(341); // levelTicks 1247: asteroid null, spawnTick 1248, retryBonus 'fastShot'
g.step(1); // asteroid {x:22, y:-12, dir:1, bonus:'fastShot', state:'flying'}, retryBonus null, spawnTick null
```

- Ушёл за край ровно через 252 тика, как в рецепте.
- Повтор назначен с задержкой 342 тика: 1248 − 906, в окне `levelTicks + 300 … + 900` = 1206…1806.
- Вылетел ровно на `spawnTick`, тик раньше астероида нет.
- Бонус тот же (`fastShot`). Стартовое смещение новое (x 34 → 22), `dir` в этом seed
  совпал случайно (1).
- Повторный прогон с перезагрузкой страницы дал те же числа — детерминизм есть.
- Повторов без ограничения (В2): в прогоне кейса 3 повтор ушёл несбитым на `levelTicks`
  1500, назначен следующий, `spawnTick` 2164 (+664, в окне).

### 3. Сбитый не возвращается — PASS

Источник: acceptance.md, кейс 2; design.md, сценарий 3.

- **Сбит повтор** (продолжение кейса 1): автоприцел под астероид + выстрелы. Попадание на
  `levelTicks` 1431, `state:'exploding'`, капсула `fastShot`. Сразу `spawnTick null`,
  `retryBonus null`, и так было все 124 тика до `over` (при 1 жизни корабль сбили враги).
- **Сбит первый астероид уровня** (уровень 2, тот же прогон, что в кейсе 4): вылет на
  `levelTicks` 609, сбит на 634. Дальше бот проверял каждый тик до конца уровня
  (`cleared` на `levelTicks` 3205, ~2570 тиков): `spawnTick` и `retryBonus` всё время
  `null`, нового `flying`-астероида нет.

### 4. Смена уровня отменяет повтор — PASS

Источник: acceptance.md, кейс 3; design.md, сценарий 4 (В4).
Новая загрузка `?seed=1&paused=1&lives=5`, старт как в кейсе 1. Дальше скриптовый бот
(`__galaxy.press/release/step` по 1 тику) сбивал врагов, уворачивался и не стрелял, если
астероид был в его колонке. События по `state()`:

| 906        | 1 playing    | ушёл; `retryBonus 'fastShot'`, `spawnTick 1248`                          |

Повтор во время `cleared` не вылетел. На уровне 2 вылетел астероид уровня (на 609).

## Для владельца

- **Частота и вид повтора:** `npm run dev`, открыть
  `http://localhost:5173/?seed=1&paused=1&lives=5`, в консоли:
  `g=__galaxy; g.press('start'); g.step(1); g.release('start'); g.resume()` и не стрелять.
  Первый астероид прилетит примерно через 11 с. Ушедший повтор вернётся через 5–15 с.
  В режиме `resume()` тики идут от rAF — числа не детерминированы.
- Быстро к кадру с повтором (пауза): `g.step(653+1+252+342+40)` после старта — повтор
  `fastShot` виден вверху слева.
