# Задача: Сбивание врагов и уровни

## Суть задачи

Выстрел игрока сбивает врагов: враг взрывается и исчезает. Строй уничтожен — пауза 1,5 с и следующий уровень. Для проверки глазами высокий уровень можно задать через `?level=N` в dev-сборке.

## Детали и требования

- `collisions.ts`: `overlaps` (строгий AABB по `Math.floor`-координатам), «выстрел игрока × враг» (попадает в самого нижнего — наибольший `y + height`, при равенстве — меньший индекс).
- `Player.removeShot`; `Enemy.kill` → `exploding` → `dead`, `stateTicks`, `isAlive`; `EXPLOSION_FRAMES` (2 кадра), `EXPLOSION_FRAME_TICKS = 8`, `EXPLOSION_TICKS = 16` (стартовые, визуальные); кадр взрыва центрируется в прямоугольнике врага; `Wave.isCleared`.
- Фазы `Battle` (`playing`/`cleared`, `phaseTicks`, `LEVEL_PAUSE_TICKS` = 1,5 с), без надписи.
- `LEVELS`: уровни 1–2 (отличаются раскладкой — точные строки в «Уточнениях для реализации»; покачивание одинаковое — 15 px/с); после конца таблицы повторяется последний уровень.
- `wave.clearShots()` при входе в `cleared` — не здесь: вражеских выстрелов ещё нет, появляется в задаче 012.
- `BattleOptions.startLevel` в `Battle`/`PlayScene`/`TitleScene`; `PlayScene(rng, starfield?, opts?)`; `?level=N` в dev `main.ts` (не целое ≥ 1 → уровень 1).
- `test-levels.ts`: `ONE_CORNER_ENEMY` (тесты сцены переходят на него), `TWO_LEVELS` для теста перехода уровня.

Точные интерфейсы, числа и порядок тика — в дизайне фичи (см. «Контекст»).

## Критерии готовности

- Тесты `collisions`, `battle`, сквозной тест `play-scene`.
- Глазами: враги взрываются; после последнего — пауза и новый строй.
- **Владелец утверждает вид взрыва.**
- Все проверки проходят: `format:check`, `lint`, `typecheck`, `test`, `build`.
- Игра остаётся рабочей; новые модули дописаны в `second-brain/architecture/overview.md`.
