# Задача: Стрельба пикирующих врагов

## Суть задачи

С 3-го уровня пикирующие враги стреляют по игроку. Попадание поражает корабль (как таран).

## Детали и требования

- `enemy-shot.ts`: 1×4, 240 px/с (решение владельца — быстрее любого пикирования), `ENEMY_SHOT_COLOR` — не белый.
- Расписание стрельбы в `Enemy`: первый выстрел в первом тике `descend`, далее каждые `ENEMY_FIRE_INTERVAL_TICKS = 20`, пока низ врага не ниже `SHIP_Y`; выстрел, отброшенный лимитом, всё равно расходует `shotsLeft` (точные правила и позиция выстрела — в «Уточнениях»).
- `diverShots` в `LevelConfig` (уровни 1–3: 0/0/1; тестовые таблицы — 0), `DiveOrder.shots`, параметр `config` у `selectSortie`.
- `MAX_ENEMY_SHOTS` = 4, создание выстрелов в `Wave`; порядок «полёт выстрелов → `enemy.update`» — новый выстрел в тике появления не движется.
- `Wave.shots`/`removeShot`/`clearShots`; «вражеский выстрел × корабль» (только при `canBeHit`); `clearShots` при входе в `cleared`.
- Инварианты: туннелирование вражеского выстрела, `ENEMY_SHOT_SPEED > diveSpeed` для каждой строки `LEVELS`.

Точные интерфейсы, числа и порядок тика — в дизайне фичи (см. «Контекст»).

## Критерии готовности

- Тесты `enemy-shot`, `enemy`, `wave`, `collisions`, `levels`.
- Глазами (`?level=3`): выстрелы видны и отрываются от врага, попадание поражает корабль.
- Все проверки проходят: `format:check`, `lint`, `typecheck`, `test`, `build`.
- Игра остаётся рабочей; новые модули дописаны в `second-brain/architecture/overview.md`.
