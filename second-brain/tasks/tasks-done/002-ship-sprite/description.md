# Задача: Спрайты и корабль на месте

## Суть задачи

Вторая задача фичи 001. Модуль спрайтов (строки пикселей + палитра) и неподвижный
корабль игрока внизу по центру игровой сцены. Владелец утверждает вид корабля глазами.

## Детали и требования

- `src/game/sprite.ts`: формат спрайта, чистая `parseSprite()` и `drawSprite(ctx, ...)`
  через `fillRect`.
- `src/game/art.ts`: `SHIP_SPRITE` 15×16 — **свой оригинальный силуэт**, 2–3 цвета
  (не копия референса). Размеры корабля выводятся из спрайта.
- `src/game/ship.ts`: `Ship` без движения — старт по центру по X, `SHIP_Y = 208`.
- Отрисовка корабля в `PlayScene`.
- `overview.md`: `sprite.ts`, `art.ts`, `Ship`.

## Критерии готовности

- `sprite.test.ts`: разбор, размеры, прозрачность, ошибки формата; `drawSprite` на
  фейковом ctx, включая несимметричный спрайт 2×3.
- `ship.test.ts`: инварианты размеров и стартовой позиции.
- Все проверки проходят.
- Глазами: корабль по центру внизу, пиксели чёткие. **Владелец утверждает вид.**
