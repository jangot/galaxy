# Задача: Улучшения в панели

## Суть задачи

Показывать полученные улучшения пули в верхней панели — два значка (быстрая пуля, две
пули). Фича 004 оставила под это место (`powerUps`).

## Детали и требования

Архитектура (`second-brain/features/006-asteroid-bonuses/design.md`, пункт 4 нарезки):

- `HudView.powerUps`, зона `POWER_UPS_ZONE` (156, 14, 18×8), два фиксированных слота,
  `drawPowerUps`; иконки — спрайты капсул.
- Литералы `HudView` в `hud-render.test.ts` (строки ~27, 70, 170) дополнить
  `powerUps: NO_POWER_UPS`.
- Значки не гаснут после гибели (улучшения до конца игры).

## Критерии готовности

- Тесты: `hudView` берёт улучшения из боя; слоты рисуются только для полученных;
  зона не пересекается с другими зонами панели.
- Проходят `format:check`, `lint`, `typecheck`, `test`, `build`.
- Приёмка глазами: значки читаются, место в панели устраивает.

## Контекст

- Фича 006: `second-brain/features/006-asteroid-bonuses/design.md` (пункт 4); фича 004 (HUD).
- Код: `src/game/hud.ts`, `hud-render.ts`, `bonus-art.ts`.

## Зависимости

Зависит от 024-multi-shot (тип `PowerUps`) и 027-capsule-bonuses (спрайты капсул).
