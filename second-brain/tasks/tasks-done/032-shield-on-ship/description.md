# Задача: Дуга щита над кораблём

## Суть задачи

Нарисовать щит над кораблём игрока: одноцветная дуга, цвет которой зависит от уровня
щита (зелёный на 5 → жёлтый на 2 → красный на 1, на 0 щита нет). Дуга мигает вместе с
кораблём во время неуязвимости. Чистая отрисовка поверх логики задачи 031.

## Детали и требования

- `art.ts`: `SHIELD_COLORS`, `SHIELD_SPRITES`, `SHIELD_OFFSET_Y` — литералы из 6 элементов
  (индекс = уровень). **`art.ts` импортирует только `sprite.ts`** (иначе цикл
  `art → player → ship → art`).
- Цвета: 5 `#4fd16a`, 4 `#8ee05a`, 3 `#c8e84a`, 2 `#ffe14f`, 1 `#ff3b3b`, 0 — нет.
- Дуга 15×4 (ширина корабля), на 5 px выше `ship.y`; хитбокс не меняется.
- `drawShip` в `battle-render.ts` рисует дугу; нет дуги при `shield = 0`, в `down`, в
  выключенной фазе мигания.

## Критерии готовности

- Новый `art.test.ts`: длины массивов = `MAX_SHIELD + 1`, ширина дуги = `SHIP_WIDTH`.
- `battle-render.test.ts`: хелпер `shipCalls` учитывает дугу во всех кейсах; кейсы «щита
  нет» (0, `down`, фаза мигания).
- `acceptance.md`: цвет меняется по ударам и капсулам `L`; различимость уровней 3 и 4;
  свой выстрел появляется у дуги (внутри неё) — оценка владельца.
- Проходят `format:check`, `lint`, `typecheck`, `test`, `build`.
