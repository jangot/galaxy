# Задача: Пиксельный шрифт

## Суть задачи

Сделать свой моноширинный пиксельный шрифт в стиле NES, чтобы рисовать текст в игре
ровно по пикселям: сейчас текст выводится через `ctx.fillText` системным шрифтом — он
размыт при целочисленном масштабе, выглядит по-разному в ОС и не проверяется тестами.
Шрифт нужен верхней панели (задача 019). В этой задаче на экран он ещё не выводится.

## Детали и требования

- `src/game/font-art.ts` — данные глифов текстовыми строками, как спрайты в `art.ts`.
  Набор: `0–9`, `A–Z`, пробел.
- `src/game/font.ts` — разбор глифов через `parseSprite` при загрузке модуля;
  `textWidth(text)` и `drawText(ctx, text, x, y, color)`. Глиф **7×7 в клетке 8×8**
  (решение владельца, В7), шрифт моноширинный, цвет задаёт вызывающий.
- `FONT_INK` — приватная константа `font.ts` (только маска, не цвет).
- `drawText` идёт своим циклом по маске пикселей и ставит `fillStyle` один раз на вызов;
  координаты на входе — целые.
- `textWidth` и `drawText` бросают ошибку на символе без глифа. У `textWidth` —
  комментарий, что хвостовой зазор 1 px оставлен намеренно.
- Шрифт — в `src/game/`, не в движке (он строится на `drawSprite`/`parseSprite`, они в
  `game/`).
- Запись о шрифте в `second-brain/architecture/overview.md`.

## Критерии готовности

- `font.test.ts`: полный набор символов, размеры глифов, `textWidth`, `drawText` (через
  `recorder()` из `canvas-test-utils.ts`: один `fillStyle`, пиксели на своих местах),
  ошибка на неизвестном символе.
- Проходят `format:check`, `lint`, `typecheck`, `test`, `build`.
- Глазами — нечего: вид глифов смотрится в задаче 019.
