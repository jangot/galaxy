# Задача: Тестовые хуки для браузерного QA-агента

## Суть задачи

Добавить в dev-сборку хуки, через которые агент-тестировщик (Claude in Chrome) может
детерминированно управлять игрой и читать её состояние. Игра рисуется на canvas, по DOM
её не проверить, а скриншоты медленные и неточные. Кроме того, агент действует медленнее
60 тиков/с, поэтому ему нужно самому управлять временем. Хуки работают только при
`import.meta.env.DEV` и в прод-сборку не попадают.

## Детали и требования

- **`?seed=N`** — seed для `createRng` вместо `Date.now()` (`src/main.ts`). Без параметра
  или при некорректном значении — как сейчас.
- **`?paused=1`** — игровой цикл не продвигает симуляцию сам; тики идут только по
  команде `step`. Отрисовка продолжает работать (чтобы скриншот показывал текущее
  состояние).
- **`window.__galaxy`** (только в DEV):
  - `step(n = 1)` — выполнить ровно `n` тиков симуляции (с текущим вводом) и
    отрисовать кадр;
  - `press(key)` / `release(key)` (или аналог) — программно задать ввод, чтобы в режиме
    паузы можно было «держать» клавишу на протяжении `step(n)`;
  - `pause()` / `resume()` — переключение режима в рантайме;
  - `state()` — JSON-снимок: текущая сцена (title / play / game over), уровень, жизни,
    счёт, игрок (позиция, жив/взрыв), враги (количество, позиции/состояния), пули,
    астероиды, капсулы/бонусы, активные улучшения. Только сериализуемые данные.
- Существующий `?level=N` сохраняется и комбинируется с новыми параметрами.
- Логику разбора параметров и построения снимка — отдельно от `main.ts`, с unit-тестами
  (разбор `seed`/`paused`, `step(n)` прогоняет ровно n тиков, `state()` отражает бой).
- Движок (`src/engine/`) не должен знать об игре: снимок состояния строит игровой код.

## Критерии готовности

- В `npm run dev` с `?seed=1&paused=1`: игра стоит, `__galaxy.step(60)` продвигает её на
  секунду, `__galaxy.state()` возвращает осмысленный JSON; два запуска с одним seed и
  одной последовательностью команд дают одинаковый `state()`.
- В `npm run build` `__galaxy` отсутствует (проверка по собранному бандлу или через
  условие `import.meta.env.DEV`).
- Unit-тесты на разбор параметров, step и снимок состояния.
- Проходят `format:check`, `lint`, `typecheck`, `test`, `build`.
