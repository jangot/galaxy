# Задача: Доп. жизни за очки

## Суть задачи

Давать дополнительную жизнь за набранные очки: на 5000, затем каждые 10000 (15000,
25000, …), всего не больше 5 жизней. Доп. жизнь, полученная, пока корабль сбит последним,
возвращает его и отменяет Game Over.

## Детали и требования

Решения владельца (фича 005, В4): пороги 5000, 15000, 25000, …; максимум 5 жизней.

- `src/game/player.ts`: `MAX_LIVES = 5`, `addLife()`, верхняя граница числа жизней в
  конструкторе.
- `src/game/score.ts`: `EXTRA_LIFE_FIRST = 5000`, `EXTRA_LIFE_EVERY = 10000`,
  `extraLivesEarned(before, after)`.
- `src/game/battle.ts`: хук в `addScore` — за каждый пройденный порог `addLife()`. Сверх
  `MAX_LIVES` доп. жизнь пропадает, порог при этом считается пройденным.
- Доп. жизнь в `down` после гибели последнего корабля отменяет Game Over — без особого
  случая в коде (подробно — `design.md`).
- Обновить `game-design.md` («Жизни») и `architecture/overview.md`.

## Критерии готовности

- Тесты порогов (несколько порогов за одно начисление), предела `MAX_LIVES`,
  `LIVES_ICON_SLOTS >= MAX_LIVES`, «доп. жизнь в `down` отменяет Game Over».
- Проходят `format:check`, `lint`, `typecheck`, `test`, `build`.
- Глазами (без отдельной приёмки): с `?level=N` набрать 5000 — появляется новая иконка.
