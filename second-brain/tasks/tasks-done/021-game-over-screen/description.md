# Задача: Экран Game Over и рестарт

## Суть задачи

Показать конец игры и дать начать заново. Когда бой переходит в фазу `over` (задача 020),
поверх летающих врагов и панели выводится надпись `GAME OVER` и мигающее `PRESS ENTER`;
по Enter игрок возвращается на заставку, звёзды продолжают движение без скачка. После
задачи игра проходит полный цикл «старт → проигрыш → старт».

## Детали и требования

Решения владельца (фича 005, В3): через 1 с после гибели последнего корабля — надпись поверх
летающих врагов, Enter → заставка. Подложка под надписью — **решается на приёмке глазами**.

- `src/game/game-over-render.ts` (новый): `drawGameOver(ctx, …, backdrop)` — `GAME OVER` и
  мигающее `PRESS ENTER` пиксельным шрифтом (фича 004), по центру через `textWidth`;
  константы раскладки и мигания; `GAME_OVER_BACKDROP = false` — выключенная чёрная
  подложка, включается одной константой.
- `src/game/scenes/play-scene.ts`: в фазе `over` рисует надпись поверх HUD; по `start`
  возвращает сцену из фабрики `exit: () => Scene` (снимает цикл импортов title ↔ play);
  `readonly starfield` для тестов.
- `src/game/scenes/title-scene.ts`: необязательный `starfield` в конструкторе
  (`TitleScene(rng, startLevel, starfield)`); передаёт в `PlayScene` фабрику выхода,
  создающую новый `TitleScene` с тем же `starfield`; `readonly starfield`.
- Enter, вернувший на заставку, не запускает сразу новую игру (`endTick`).
- `src/engine/` не меняется.
- Обновить `game-design.md` («Поражение игрока»/Game Over) и `architecture/overview.md`.

## Критерии готовности

- Тесты: `game-over-render` (обе ветки подложки, через `recorder()`), сцен
  (`play-scene`, `title-scene`): полный цикл на уровне 1 с тремя жизнями — `hit()` до
  `over`, Enter → заставка, тот же `starfield`, `player.lives === START_LIVES` в новой
  игре (**без** `battle.score === 0` — счёта ещё нет, проверка добавляется в 022).
- Проходят `format:check`, `lint`, `typecheck`, `test`, `build`.
- Приёмка глазами владельцем (`acceptance.md`): надпись и мигание, **читаемость без
  подложки** (если плохо — включить `GAME_OVER_BACKDROP`), рестарт, звёзды без скачка.
