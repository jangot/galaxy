# Задача: Несколько выстрелов и скорость пули

## Суть задачи

Подготовить корабль игрока к улучшениям пули: вместо одного выстрела — список выстрелов
с пределом, у каждого выстрела — своя скорость. Улучшений в игре взять пока неоткуда,
поэтому внешне игра не меняется; проверка — тестами.

## Детали и требования

Решения владельца (фича 006, В6, В7):

- Быстрая пуля — 360 px/с (×1,5; 6 px/тик), обычная — 240 px/с. Скорость не
  складывается.
- «Две пули» — до двух своих выстрелов на экране одновременно, стрельба по нажатию.
- Улучшения действуют до конца игры (гибель корабля их не снимает).

Архитектура (`second-brain/features/006-asteroid-bonuses/design.md`, пункт 1 нарезки):

- `bonus.ts` (новый) — типы бонусов и `PowerUps`.
- `Shot.speed` + `FAST_SHOT_SPEED`, `spawnShot(speed?)`.
- `Player.shots` / `removeShot(shot)` — **замена массива через filter, не мутация**;
  `maxShots`, `powerUps`, `grantPowerUp` (возвращает `boolean` — было ли полезно).
  Геттер `shot` для совместимости не оставлять.
- Правило 1 коллизий — по всем выстрелам (до трёх `Kill` за тик); `drawBattle` рисует
  все выстрелы.
- Помощник `onlyShot` в `src/game/test-shots.ts`; перевод ~60 мест `shot → shots` в
  тестах (`player`, `play-scene`, `collisions`, `battle`, `battle-render`, `hud`).
- Обновить комментарии-контракты: класс-док `Player` («its single shot», автомат
  Ready/InFlight, `removeShot`), `resolveCollisions` «at most two» → три,
  `drawBattle` «player shot» → все выстрелы.

## Критерии готовности

- Тесты: `maxShots` 1/2 по улучшению, скорость пули по улучшению, `grantPowerUp`
  повторно → `false`; «оба выстрела в одном тике поражают две цели»; инвариант пробоя
  врагов быстрой пулей по `levelConfig(1..20)` (в `shot.test.ts`).
- Поведение без улучшений не изменилось (существующие тесты зелёные после перевода).
- Проходят `format:check`, `lint`, `typecheck`, `test`, `build`.
