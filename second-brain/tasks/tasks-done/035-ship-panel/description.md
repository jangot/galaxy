# Задача: панель корабля

## Суть задачи

Верхняя панель становится приборной панелью корабля: непрозрачная плита во всю ширину с
рамкой, чёрными окнами приборов вокруг значений и лампами улучшений. Данные и раскладка
по X — из задачи 034; здесь — вид и вертикальные координаты. Приёмка глазами.

## Детали и требования

- Высота 24 px, поле не сдвигается (В6); плита непрозрачная (В5): светлая верхняя кромка
  (y = 0), тёмный нижний скос 2 px (y = 22…23), заклёпки по 1 px в углах.
- Новые Y: подписи `HUD_LABEL_Y` 4 → 3 (y = 3…9), значения `HUD_VALUE_Y` 14 → 12 (цифры
  12…18, значки и шкала 12…19, `SHIELD_SEGMENT_Y` → 14); окна приборов y = 11…20.
- Геометрия: `valueRow(zone)`, `HUD_WINDOW_PAD = 1`, `HUD_WINDOWS` выводятся из зон (по
  одному окну на зону, окно = строка значений ± 1 px), `PANEL_ZONE`.
- Отрисовка: экспортируемый `drawPanel` — первым в `drawHud`.
- Цвета панели `PANEL_*_COLOR` в `art.ts`; попарно различимы между собой, с `#000` (окно) и
  `SHIELD_GAUGE_EMPTY_COLOR` (тест в `art.test`).
- Лампы (В7): `CAPSULE_OFF_SPRITES` в `bonus-art.ts` — та же капсула с буквой в тёмной
  палитре; не полученное улучшение — погасшая лампа, полученное — горит (обычный значок).
  Тест в `bonus-art.test`: размер как у горящего, цвета без `#000` и не пересекаются с
  цветами горящего спрайта.
- Существующие тесты с меняющимися ожиданиями — строки «035» в таблице «Тестирования»
  дизайна; во всех тестах `hud-render.test.ts`, фильтрующих по координатам или цвету,
  сперва отрезаются `draw(drawPanel).length` вызовов. Проверки не ослабляются.
- Астероид, сбитый под плитой, — как есть (В8).
- Стиль — NES/Денди, свой оригинальный рисунок; конкретные оттенки подбираются в палитре.

## Критерии готовности

- Новые и обновлённые тесты по разделу «Тестирование» дизайна для 035; полный набор
  проверок зелёный.
- Глазами: плита, кромка, скос, окна, лампы, цвета — в духе NES, цифры читаемы; враги и
  астероид выезжают из-под панели без артефактов; взрыв на апексе дуги не задевает панель.
- Документы: `second-brain/architecture/overview.md`; раздел «Экран» в `game-design.md`
  сверить с итогом.
