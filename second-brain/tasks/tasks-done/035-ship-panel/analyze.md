# Анализ: панель корабля (035)

Рамка — согласованный `second-brain/features/009-high-score-ship-panel/design.md` (раунд 3),
пункт 2 нарезки. Задача 034 (рекорд, `HI_ZONE`, сдвиг `LEVEL`/улучшений по X) уже
реализована в рабочем дереве — анализ опирается на неё. Номера строк — по текущему
рабочему дереву (после 034).

## Общее описание функциональности

Верхняя полоса 24 px перестаёт быть «текстом поверх звёзд» и становится приборной
панелью корабля (В5): непрозрачная плита во всю ширину закрывает звёзды и всё, что
пролетает под ней (возвращающиеся враги, астероид — «выезжают» из-под нижнего края).
У плиты светлая верхняя кромка (y = 0), тёмный нижний скос 2 px (y = 22…23), заклёпки
по 1 px в углах. Значения (счёт, рекорд, уровень, лампы, шкала щита) — в чёрных окнах
приборов, по одному окну на секцию. Улучшения — две лампы (В7): не полученное —
погасшая капсула с буквой в тёмной палитре, полученное — обычный горящий значок.
Подписи и значения поднимаются на 1–2 px, чтобы окна и скос уместились в 24 px; поле не
сдвигается (В6). Раскладка по X не меняется (сделана в 034). Состояния и анимации нет —
плита статична, лампы — чистая функция `view.powerUps`.

Окна по X (проверено по текущим зонам): `SCORE` 7…56, `HI` 63…112, `LEVEL` 119…160,

x = 0…6 и 249…255 (место для заклёпок и боковых кромок). По Y: низ подписи 9 < верх окна
11; низ окна 20 < скос 22. Окно асимметрично вокруг цифр (1 px сверху, 2 px снизу: цифры
12…18, окно 11…20), потому что высота окна берётся от `HUD_ICON_SIZE`, общей для текста и
значков, — принято дизайном, оценивается глазами.

## Точки встраивания

- **Отрисовка:** `drawHud` (`hud-render.ts:39-45`) — первым вызовом `drawPanel(ctx)`
  (экспортируемая): плита (первый `fillRect` = весь `PANEL_ZONE`), кромка, скос, окна
  (`HUD_WINDOWS`, `#000`), заклёпки. Затем секции, как сейчас.
- **Лампы:** `drawPowerUps` (`hud-render.ts:98-104`) — для каждого слота
  `CAPSULE_SPRITES[kind]`, если улучшение есть, иначе `CAPSULE_OFF_SPRITES[kind]` (сейчас
  выключенный слот пуст).
- **Сцена:** `PlayScene.render` (`play-scene.ts:78-84`) уже рисует HUD после боя — плита
  автоматически закроет врагов/астероид при y < 24; код сцены не меняется, кроме
  устаревшего комментария `// no background: text over the battle` (`:82`) и докстринга
  `drawHud` («no background»).
- Цикл, ввод, `Battle`, `dev-snapshot` — не затрагиваются. `TitleScene` HUD не рисует.

## Тестируемость

Всё, кроме вкуса цветов, покрывается unit-тестами без canvas (`recorder()`):

- **`hud.test.ts`:** `valueRow` для текстовой зоны и для зон строки значений (у
  `SHIELD_ZONE`/`POWER_UPS_ZONE` `valueRow` = зона); `PANEL_ZONE` = вся полоса;
  `HUD_WINDOWS` — по одному на зону `HUD_ZONES`, каждое внутри `PANEL_ZONE`, попарно не
  пересекаются, содержит `valueRow` своей зоны, верх окна > низа подписи
  (`HUD_LABEL_Y + GLYPH_HEIGHT ≤ окно.y`), низ окна не заходит на скос (≤ 22).
  Существующие «zone spans both text rows», «label row above value row», `HUD_HEIGHT ≤ 28`,

## Зависимости и ограничения

- Зависит от 034 — выполнено в рабочем дереве: `HI_ZONE` в `HUD_ZONES`, окна строятся по
  всем пяти зонам.
- Производительность: плита — порядка 10–20 `fillRect` за кадр, погасшие лампы +2 спрайта
  8×8 (≈ 100 `fillRect` 1×1) — пренебрежимо на 60 тиках; offscreen-кэш отвергнут дизайном.
- Граница модулей: `art.ts` импортирует только `sprite.ts` — поэтому цвета ламп живут в
  `bonus-art.ts` и проверяются в `bonus-art.test.ts`; `bonus-art.ts` получит
  `import type { PowerUpKind }`.
- Цвет окна — `#000` (как в дизайне). Если завести для него константу, её нельзя включать
  в набор `PANEL_*_COLOR`, проверяемый на отличие от `#000` (тест упадёт сам на себе) —
  назвать иначе (напр. `HUD_WINDOW_COLOR`) или оставить литерал; решить в плане.
- Порядок секций: дизайн («Поток тика», п. 2.2) перечисляет «лампы, шкала», а код рисует
  щит раньше улучшений (`hud-render.ts:43-44`). Порядок на пиксели не влияет (зоны не
  пересекаются); оставить как в коде — эталоны `toEqual` в тестах так и построены.
- Объекты под плитой (враги с `y = -height`, астероид `y = -12`, сбитый под плитой
  астероид — В8) — ожидаемое поведение, код боя не меняется.
