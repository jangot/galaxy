# Задача: Движение корабля

## Суть задачи

Третья задача фичи 001. Корабль ездит влево-вправо со скоростью 120 px/с (2 px/тик),
упирается в края экрана. Управление идёт через намерение игрока (`PlayerIntent`),
а не напрямую через клавиатуру.

## Детали и требования

- `Ship.update` с зажимом позиции в `[0, SCREEN_WIDTH - SHIP_WIDTH]` (`[0, 241]`),
  `SHIP_SPEED = 120`. Отпустил — встал сразу (без инерции). Обе стороны — стоит.
- `MoveDir`, `PlayerIntent { move, fire }`, `readIntent(input)`.
- `Player` (пока только корабль), подключение в `PlayScene`.
- Правило скоростей: `SPEED * TICK_SECONDS` — целое число px/тик; закрепить тестом.
- `overview.md`: `Player`, `PlayerIntent`, правило скоростей.

## Критерии готовности

- `ship.test.ts`: движение, зажим у обоих краёв (прямой установкой координат),
  инвариант целой скорости; тесты `readIntent`; `play-scene.test.ts` — движение через
  `step()`.
- Все проверки проходят.
- Глазами: ездит ровно, без подёргивания, упирается в края.
