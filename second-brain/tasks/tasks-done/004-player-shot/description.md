# Задача: Выстрел игрока

## Суть задачи

Четвёртая задача фичи 001. Корабль стреляет вверх; на экране не больше одного своего
выстрела; стрельба только по нажатию.

## Детали и требования

- `src/game/shot.ts`: `Shot` 1×4, `SHOT_SPEED = 240` (4 px/тик), признак «ушёл за экран».
- `SHOT_COLOR = '#ffffff'` в `art.ts`; `Ship.spawnShot` — из носа корабля.
- В `Player`: единственный выстрел (`Shot | null`), порядок тика — движение → полёт и
  удаление выстрела → огонь (выстрел, исчезнувший в этом тике, сразу освобождает место).
- Огонь только по нажатию: удержание не стреляет повторно, нажатие во время полёта
  игнорируется и не запоминается. Выстрел не следует за кораблём.
- Отрисовка выстрела в `PlayScene`.
- `overview.md`: `Shot`, логика выстрела.

## Критерии готовности

- `shot.test.ts`, `player.test.ts` (границы — прямой установкой координат);
  `play-scene.test.ts`: огонь, удержание без очереди.
- Все проверки проходят.
- Глазами: один выстрел за раз, после ухода за верх снова можно стрелять.

по нажатию).
