# Задача: Модель астероида

## Суть задачи

Сделать логику астероида и поля бонусов без встраивания в игру: полёт наискосок,
выбор момента появления раз за уровень, разбивание и очки. Проверка — только тестами.

## Детали и требования

Решения владельца (фича 006, В1–В3, В5, В7, В9):

- Астероид падает сверху наискосок через строй, кораблю безопасен; 60 px/с вниз и
  30 px/с вбок (1 и ½ px/тик, ADR 002/003). Стартует над верхним краем у одного из
  верхних углов, направление и сдвиг внутрь (0…118 px) — из rng поля; за боковые края не
  выходит, уходит только за низ.
- Один за уровень, в случайный момент 5–15 с (300…900 тиков) фазы `playing`. Уровень
  зачищен раньше — астероида в этом уровне нет. Поле занято — появление ждёт.
- Разбивается с одного попадания.
- Вид бонуса — случайно, поровну из трёх, выбирается при появлении; порядок вызовов rng:
  `dir → offset → bonus`.
- Очки: 100 с надбавкой уровня, как у врагов.

Архитектура (`second-brain/features/006-asteroid-bonuses/design.md`, пункт 2а нарезки):

- `asteroid.ts` (новый) — `Asteroid(dir, offset, bonus)`, 12×12.
- `bonus-field.ts` (новый) — тик уровня, `startLevel`, отложенное появление,
  `update(dt, spawning)` без умолчания, `hitAsteroid` только разбивает (капсула — в 027).
- `score.ts` — `levelPoints` (выделить из `killPoints`) и `asteroidPoints`.

## Критерии готовности

- Тесты: траектория и инвариант «весь полёт на экране» (крайние сдвиги и оба
  направления); инвариант пробоя астероида быстрой пулей (`asteroid.test.ts`); окно
  появления, «зачищен раньше — нет», отложенное появление; детерминизм по seed;
  `asteroidPoints` по уровням, `killPoints` не изменился.
- В игру не встроено, поведение игры не меняется.
- Проходят `format:check`, `lint`, `typecheck`, `test`, `build`.
