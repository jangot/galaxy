# Задача: Шкала щита в панели

## Суть задачи

Заменить в верхней панели иконки жизней (в 031 временно показывающие уровень щита) на
шкалу щита из 5 сегментов без подписи. Залито столько сегментов, каков уровень щита,
цветом текущего уровня; пустые — тёмно-серые.

## Детали и требования

- Зона прежних иконок (200…247 × 14…21): 5 сегментов 8×4 с шагом 10, `SHIELD_ZONE`.
- Цвет заливки — `SHIELD_COLORS[shield]` из `art.ts` (задача 032);
  `SHIELD_GAUGE_EMPTY_COLOR` для пустых сегментов — вводит эта задача.
- `HUD_ICON_*` вместо `LIFE_ICON_*`; удалить `LIFE_ICON_SPRITE` и `LIVES_ICON_SLOTS`;
  `drawShield` вместо `drawLives`.

## Критерии готовности

- Тесты по таблице «033» design.md (hud, hud-render) зелёные.
- `game-design.md` — раздел HUD по «Правке game-design.md»; `overview.md`.
- `acceptance.md`: шкала меняется по ударам и капсулам; цвет пустых сегментов — оценка
  владельца.
- Проходят `format:check`, `lint`, `typecheck`, `test`, `build`.

## Контекст

Фича 008: `second-brain/features/008-ship-shield/design.md`, пункт нарезки 3
(033-hud-shield-gauge), В9 (шкала без подписи); фича 004 (HUD).

## Зависимости

Зависит от 031-shield-logic и 032-shield-on-ship (`SHIELD_COLORS`).

Нет — приёмка владельцем пройдена.
