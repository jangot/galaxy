# Задача: Поражение игрока тараном

## Суть задачи

Пикирующий враг, столкнувшийся с кораблём, уничтожает его (и гибнет сам). Корабль исчезает на 1 с, затем появляется по центру и 2 с мигает — неуязвим, но управляем. Уровень не перезапускается; жизней пока нет.

## Детали и требования

- `SHIP_START_X` в `ship.ts`.
- Автомат корабля в `Player`: `active` → `down` → `invulnerable`, `hit()`, возрождение по «Правилу тиков переходов» из дизайна.
- Правило тарана в `collisions.ts` (гибнут оба, враг считается уничтоженным).
- `canBeTargeted` → `targetX = null`, пока корабль `down`.
- Рендер взрыва корабля (те же `EXPLOSION_FRAMES`, по центру корабля, пока `stateTicks < EXPLOSION_TICKS`) и мигания (`BLINK_TICKS = 4`, видим при `Math.floor(stateTicks / BLINK_TICKS) % 2 === 0`); тест-инвариант `EXPLOSION_TICKS < DOWN_TICKS`.
- `DOWN_TICKS = 60`, `INVULNERABLE_TICKS = 120`.

Точные интерфейсы, числа и порядок тика — в дизайне фичи (см. «Контекст»).

## Критерии готовности

- Тесты `player` (два теста тика возрождения: `IDLE` и `move: 1` + огонь), `collisions`, `battle-render`.
- Глазами: таран взрывает корабль и врага, корабль возвращается и мигает.
- Все проверки проходят: `format:check`, `lint`, `typecheck`, `test`, `build`.
- Игра остаётся рабочей; новые модули дописаны в `second-brain/architecture/overview.md`.
