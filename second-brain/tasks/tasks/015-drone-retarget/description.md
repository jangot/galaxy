# Задача: Переприцеливание drone

## Суть задачи

`drone` по ходу пике раз в 0,5 с заново берёт цель — текущий X корабля — и сворачивает к
ней, а не летит по одному прицелу, взятому в начале. Уход одним движением в начале пике
больше не гарантирует безопасность. Меняется только профиль `drone` в модели руления из
задачи 014.

## Детали и требования

- `DRONE_RETARGET_TICKS = 30` (утверждено владельцем, В1); профиль
  `drone: { retargetTicks: DRONE_RETARGET_TICKS, turnTicks: 0, maxVx: 1 }`.
- Цель берётся в тики `descend` 1, 31, 61, …; без зигзага (В1).
- Если в 1-м тике цели нет (корабль `down`), `drone` подхватывает корабль на ближайшем
  переприцеливании после возрождения (В3, принято владельцем).
- Тесты «fixed …» переносятся на `raider` (у него поведение «один раз» сохраняется).
- Обновить `second-brain/game-design.md` («Пикирование»).

## Критерии готовности

- Тесты: цель держится `N` тиков, на тике `1 + N` берётся новая и `vx` меняет знак;
  подхват корабля после `null`-цели в 1-м тике.
- Глазами (`?level=1`, `?level=5`): `drone` заметно меняет курс по ходу пике.
- Проходят `format:check`, `lint`, `typecheck`, `test`, `build`.
