# Приёмка: 014 — модель руления

Код реализован, автоматические проверки зелёные (`format:check`, `lint`, `typecheck`,
`test`, `build`). Задача не перенесена в `tasks-done`: критерий «Глазами игра не меняется»
утверждает владелец.

## Что утвердить

Поведение врагов в `descend` **не изменилось** по сравнению с `main` (рефакторинг на
`steering.ts` + `ENEMY_KINDS[kind].steer`).

## Как проверить

`npm run dev`, уровни `?level=1` … `?level=5`:

1. `drone` — после дуги летит к точке, где был корабль в начале пике, дальше прямо вниз;
   за кораблём не довёртывает.
2. `striker` — ведёт корабль без задержки, 1 px/тик; от него можно уйти (корабль быстрее).
3. Группы `raider` (уровни 4–5) — идут строем с прежними интервалами, у края экрана
   сдвигаются целиком, не сжимаясь.
4. Дуга отрыва, стрельба пикирующих, уход за низ и возврат в строй — как раньше.

После утверждения — перенести папку в `second-brain/tasks/tasks-done/`.
