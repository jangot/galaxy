# Приёмка: задача 019 — верхняя панель (HUD)

Автоматические проверки пройдены (`format:check`, `lint`, `typecheck`, `test`, `build`).
Осталось утвердить глазами. `npm run dev`, Enter на заставке.

## Утвердить

1. **Раскладка панели.** Вверху: слева `SCORE` красным и `000000` белым под ним, по центру
   `LEVEL` / `1` (номер по центру под подписью), справа три иконки корабля в строке
   значений; правый отступ ≈ левому.
2. **Шрифт** (из задачи 018) читается при масштабе ×2…×4 (менять размер окна), вид глифов
   устраивает.
3. **Рисунок иконки жизни** (7×8, `LIFE_ICON_SPRITE` в `src/game/art.ts`) устраивает.
   Правка — только массив строк; тесты держат предел 8×8.

## Проверить

4. Панель не налезает на строй при покачивании ±16 px; на `?level=4` / `?level=5` верхний
   ряд `raider` и взрыв врага, сбитого сразу после вылета (на апексе дуги), — ниже панели.
5. Враг, возвращающийся в строй сверху, и выстрел игрока проходят под текстом; звёзды
   видны под панелью.
6. Уничтожить строй → после паузы ≈ 1,5 с номер уровня меняется вместе с появлением волны.
7. `?level=9` → уничтожить строй → `10`; номер по центру под `LEVEL` (`9` и `10` оба
   центрированы, сдвиг на 9 → 10 ожидаем; правка владельца 2026-11-11).

## Как закрыть

Всё устраивает — перенести папку задачи в `second-brain/tasks/tasks-done/`. Замечания по
рисунку иконки или шрифту — правка строк в `art.ts` / `font-art.ts` без изменения кода.
