# Задача: Инерция striker

## Суть задачи

`striker` продолжает следить за кораблём каждый тик, но его боковая скорость меняется с
инерцией: на развороте корабля враг проскакивает, затем «стоит» по X и только потом
догоняет. От него можно уйти финтом, но не стоя на месте. Меняется профиль `striker` в
модели руления из задачи 014 и тесты, которые были завязаны на мгновенное слежение.

## Детали и требования

- `STRIKER_TURN_TICKS = 8` (утверждено владельцем, В2); профиль
  `striker: { retargetTicks: 1, turnTicks: STRIKER_TURN_TICKS, maxVx: 1 }`.
- В начале `descend` `striker` продолжает боковую скорость дуги вылета (В2: сохранить;
  ослабление фланговых `striker` ≈ 22 px принято). Запасной вариант на случай провала
  приёмки — старт с `vx = 0` (см. «Альтернативы» дизайна).
- Раскладка разворота при `T = 8`: 7 тиков прежним курсом, 8 тиков `vx = 0`, затем
  разворот; у стоящей цели виляние ≤ `T − 1` px.
- Перенос пяти механических тестов «Enemy aim» со `striker` на `drone` /
  `steering.test.ts` без подгонки ожиданий (перечень — «Тестирование» дизайна).
- `wave.test.ts`: «passes targetX to the enemies» — с `S` на `D`.
- `battle.test.ts`: «Battle aim» — прогон `1 + P + 160`, допуск `≤ T − 1`;
  «no target while down» — `x` стабилен не позже чем через `T` тиков.
- Обновить `second-brain/game-design.md`, `second-brain/architecture/overview.md`.

## Критерии готовности

- Тесты `striker`: продолжение `vx` дуги, раскладка разворота, размах виляния, затухание
  при `targetX = null`, `vx = 0` у стены.
- Сценарий уходимости (`diveSpeed` 180 и 120): стоящий корабль — таран, финт —
  разошлись; контроль в `steering.test.ts`: при `turnTicks = 0` — таран, при
  `STRIKER_TURN_TICKS` — разошлись.
- Глазами (`?level=2`, `?level=5`): `striker` опасен, но уходится финтом; переход дуги в
  пике плавный; отдельно — фланговые `striker` (не слишком ли слабы).
- Проходят `format:check`, `lint`, `typecheck`, `test`, `build`.
