# Гейм-дизайн

Живой документ: что за игра и что уже решено. Обновлять по мере принятия решений.

## Концепция

Оригинальный fixed shooter в духе аркад 8-битных приставок. Референсы по ощущению —
`references/menu-reference.png`, `references/game-reference.png`. Название, логотип,
спрайты, звуки — **свои**, не копируем чужие.

Рабочее название: **Galaxy** (может поменяться).

## Экран

- 256×240 логических пикселей, чёрный фон, мерцающие разноцветные звёзды, медленно
  ползущие вниз (сделано: `src/game/starfield.ts`).
- HUD сверху: счёт игрока, рекорд, оставшиеся жизни (иконки кораблей), счётчик волн
  (флажки).

## Механики (план)

- **Игрок:** корабль внизу, движется только влево-вправо, на экране одновременно не
  больше одного своего выстрела.
- **Строй врагов:** несколько рядов, разные типы по рядам (от простых снизу к ценным
  сверху), строй покачивается влево-вправо.
- **Пикирование:** враги по одному или группами вылетают из строя, летят по дуге к
  игроку и стреляют; командир может уводить с собой эскорт.
- **Очки:** больше за врагов в полёте, чем в строю; бонус за командира с эскортом.
- **Волны:** строй уничтожен → следующая волна, сложность растёт.
- **Жизни:** стартовый запас, доп. жизнь за порог очков, Game Over → рекорд.
- **Меню:** логотип, выбор режима (1 игрок; 2 игрока поочерёдно — под вопросом).
