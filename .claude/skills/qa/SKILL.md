# QA-прогон в браузере

Проверка поведения игры в реальном браузере — то, что unit-тесты не покрывают:
сцены целиком, ввод, HUD, взаимодействие сущностей. Вопросы вкуса (цвета, ощущение)
агент не решает — помечает их для владельца.

## Аргументы

- `$ARGUMENTS` — номер задачи (обязателен) и, опционально, дополнительные кейсы или
  указания свободным текстом. Без номера — сообщить и остановиться.
- Номер фичи вместо задачи: `f006` / `feature 006` — тогда кейсы берутся из
  `second-brain/features/{NNN}-*/` (design.md, README) и `acceptance.md` её задач.

## Подготовка (в основной сессии)

1. Найти папку: `ls second-brain/tasks/tasks/ second-brain/tasks/tasks-done/ | grep '^{NNN}-'`
   (для фичи — `ls second-brain/features/ | grep '^{NNN}-'`). Нет — сообщить и
   остановиться.
2. Проверить, что Claude in Chrome доступен (инструменты `mcp__claude-in-chrome__*` есть
   в сессии). Нет — сообщить владельцу, что нужно расширение Chrome, и остановиться.
3. Проверить наличие dev-хуков: `grep -rn "__galaxy" src/`. Нет — предупредить, что
   прогон будет ограниченным (клавиатура + скриншоты в реальном времени, много BLOCKED),
   и предложить сначала задачу 029 (dev-хуки); продолжать, только если владелец согласен
   или это явно указано в аргументах.

## Запуск

Через **Agent tool** (`subagent_type: tester`), не через `Skill`. Промпт:

```
QA-прогон задачи {NNN} (папка: {путь}).
Источники кейсов: acceptance.md, description.md (критерии готовности), дизайн фичи.
Дополнительно от владельца: {доп. указания из аргументов или «нет»}.
Отчёт — qa-report.md в папке задачи. Следуй инструкции агента tester.
```

## После прогона

Кратко пересказать владельцу (отчёт агента он не видит):

- итог PASS / FAIL / OWNER / BLOCKED и путь к `qa-report.md`;
- баги — по одной строке; предложить завести задачу (`/new-task`) или передать
  разработчику (`/fix-tests` / `/do` по ситуации) — **не запускать автоматически**;
- OWNER-кейсы — что посмотреть глазами и с каким URL;
- чего не хватило агенту (dev-хуки, сценарии) — предложить задачу.

## Заметки

- Агент не меняет код и не отмечает чекбоксы приёмки — финальное решение за владельцем.
- Прогон занимает время и идёт в браузере владельца (новая вкладка); пользоваться
  этой вкладкой во время прогона не стоит.
